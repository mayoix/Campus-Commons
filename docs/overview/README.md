# Project overview

Campus Commons is Team **She++**'s **2026 Hackathon HackU** submission for **Financial Technology Problem 2 — Recognise Value That Gets Overlooked**.

The overlooked value is idle equipment, spaces, skills and people capacity distributed among campus organizations. The product makes temporary access discoverable, builds complete Mission Plans, applies a preference-aware fairness batch and preserves bookings, contribution, credit and dispute records.

The current English MVP is hosted on Render, backed by Supabase Postgres and private Storage. A credential-free local SQLite demo and a private collaborator launcher remain available. Admin Demo studio animates four scripted cases; actual business operations and repeatable evaluation are described separately.

See the [main README](../../README.md) for current implementation, operation, deployment and limitations, and [requirements/evidence](../REQUIREMENTS_AND_EVIDENCE.md) for judging coverage.
