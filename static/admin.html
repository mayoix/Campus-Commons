Admin console sign in

Use this console to run allocation batches, test fairness, manage resources and organizations, and run demos. These controls are hidden from regular users.

Use CAMPUS_ADMIN_PASSWORD from your private configuration. If omitted with double-click startup, view the generated password privately in .launcher-admin-password.
